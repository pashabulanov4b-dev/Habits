# Звички — трекер з мінімумом (PWA)

Застосунок для iPhone без Xcode і без App Store: відкривається на весь екран, працює без інтернету,
синхронізує дані з хмарою і надсилає push-нагадування. Дизайн — темний Liquid Glass.

## Що вміє

- **Повний екран**: `display: standalone`, статус-бар `black-translucent`, відступи під «чубчик» і home-індикатор, splash-екрани для всіх iPhone.
- **Офлайн**: service worker кешує весь застосунок — він відкривається навіть у режимі польоту.
- **Дані на телефоні**: кожна відмітка одразу пишеться в IndexedDB. Без інтернету вона чекає в черзі.
- **Синхронізація**: щойно з'являється інтернет (а також при кожному відкритті і раз на хвилину, поки застосунок відкритий), зміни йдуть на сервер, а звідти підтягуються зміни з інших пристроїв. Конфлікти вирішуються за принципом «перемагає новіша зміна».
- **Сповіщення**: щодня в обраний час, *тільки якщо* ще не все відмічено. У тексті — які звички залишились.
- **Анімації**: перехід між екранами, поява карток каскадом, «пружинні» відмітки з хвилею, кільце прогресу з лічильником, конфеті, коли день зараховано, ріст стовпчиків, плаваючий фон під склом. Якщо в iPhone увімкнено «Зменшення руху», анімації вимикаються.

## Структура

```
public/            — сам застосунок (те, що бачить телефон)
  index.html, css/app.css, js/app.js
  js/db.js         — локальне сховище (IndexedDB)
  js/sync.js       — черга змін і синхронізація
  js/notify.js     — підписка на push
  sw.js            — офлайн-кеш і показ сповіщень
api/               — серверні функції Vercel
  sync.js          — злиття даних у Redis
  subscribe.js     — збереження push-підписки та часу нагадування
  cron.js          — розсилка нагадувань
.github/workflows/reminders.yml — розклад (кожні ~15 хв, безкоштовно)
scripts/           — генерація іконок, ключів, локальний сервер
```

## Запуск (≈15 хвилин, усе безкоштовно)

1. **GitHub.** Створи репозиторій і завантаж туди цю папку.
2. **Vercel.** Add New → Project → імпортуй репозиторій. Framework Preset: **Other**, нічого не змінюй → Deploy.
3. **Сховище.** У проєкті Vercel: Storage → Create → **Upstash for Redis** (безкоштовний план) → Connect to project. Змінні `KV_REST_API_URL` і `KV_REST_API_TOKEN` додадуться самі.
4. **Ключі для сповіщень.** На будь-якому комп'ютері з Node.js: `node scripts/vapid-keys.mjs`. Скопіюй три рядки у Vercel → Settings → Environment Variables:
   - `VAPID_PUBLIC_KEY`
   - `VAPID_PRIVATE_KEY`
   - `CRON_SECRET`
   - і ще `VAPID_SUBJECT` = `mailto:твоя@пошта`
   Потім Deployments → … → Redeploy.
5. **Розклад нагадувань.** У GitHub-репозиторії: Settings → Secrets and variables → Actions → New repository secret:
   - `APP_URL` = адреса з Vercel, напр. `https://habits-pavlo.vercel.app`
   - `CRON_SECRET` = той самий, що у Vercel
   Перевірка: вкладка Actions → «Нагадування про звички» → Run workflow.
6. **iPhone.** Відкрий адресу в **Safari** → «Поділитися» → «На початковий екран». Далі відкривай тільки з іконки → ⚙️ → увімкни «Нагадування» і дозволь сповіщення.

## Важливо знати про iPhone

- Сповіщення працюють лише у встановленому застосунку (iOS 16.4+), не у вкладці Safari.
- iOS не дає вебзастосункам синхронізуватись у фоні: офлайн-зміни відправляться, коли ти наступного разу відкриєш застосунок з інтернетом.
- GitHub може запускати розклад із затримкою 5–15 хв, тож нагадування на 20:00 прийде приблизно о 20:00–20:15.
- GitHub вимикає розклад у репозиторії без активності 60 днів — тоді просто натисни «Enable workflow» у вкладці Actions.
- Інший пристрій: ⚙️ → «Код синхронізації» → скопіюй і встав на іншому телефоні в «Підключити інший пристрій».

## Розробка

```bash
npm run dev     # локальний сервер з імітацією API: http://localhost:5173
npm test        # тести злиття даних і нагадувань
npm run images  # перегенерувати іконки та splash (Python + Pillow)
```

Після зміни списку файлів у `public/` збільш `VERSION` у `public/sw.js`.
